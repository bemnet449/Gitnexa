# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-09-16

### Changed

- Renamed package and CLI command to `gitnexa`

## [1.0.0] - 2026-08-09

### Added

- Initial release of Gitnexa CLI
- `gitnexa analyze` — analyze staged Git changes
- `gitnexa commit` — generate, validate, score, and create Conventional Commits via Gemini
- `gitnexa history` — show recent commits with optional `--limit`
- `gitnexa explain` — explain a commit in simple technical language
- Conventional Commit validation and local quality scoring
- Service-based architecture prepared for future editor integrations
