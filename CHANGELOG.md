# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.0.0] - 2026-08-09

### Added

- Initial release of GitSense CLI
- `gitsense analyze` — analyze staged Git changes
- `gitsense commit` — generate, validate, score, and create Conventional Commits via Gemini
- `gitsense history` — show recent commits with optional `--limit`
- `gitsense explain` — explain a commit in simple technical language
- Conventional Commit validation and local quality scoring
- Service-based architecture prepared for future editor integrations
